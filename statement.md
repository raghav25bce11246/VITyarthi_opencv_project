# Project Statement

## Project title
Image Processing Basics with OpenCV

## Problem statement
Beginners often learn image processing as separate OpenCV functions without seeing how those functions fit into one complete workflow. This project combines the basic operations from the VITyarthi OpenCV session into a small reusable image-processing pipeline.

The system accepts an image, validates it, performs common introductory operations, and saves the results in a clear output folder so that the effect of each operation can be inspected.

## Scope
The project focuses on introductory image processing concepts:

- reading and validating an image
- saving images
- grayscale conversion
- Blue, Green and Red channel separation
- average and Gaussian blurring
- writing a simple processing summary

Advanced computer vision tasks such as object detection, face recognition and deep learning are outside the current scope.

## Target users
- students learning OpenCV
- beginners practicing image processing
- users who want a small command-line demonstration of basic OpenCV operations

## High-level features
1. Image loading and validation
2. Grayscale image generation
3. BGR channel splitting and visualisation
4. Average and Gaussian blurring
5. Automatic saving of results
6. Text summary of processed image and outputs
7. Jupyter Notebook demonstration
8. Basic automated tests
